CSS Box Model

Every HTML element is a box. This example labels each layer and uses box-sizing: border-box so the declared width includes padding and border.

MARGIN — space outside the border

BORDER — the edge around the element

PADDING — space inside the border

CONTENT Text, images, or other child elements

What does border-box do?

With box-sizing: border-box, an element's declared width includes its content, padding, and border. Margin stays outside the declared width and creates space between elements.
